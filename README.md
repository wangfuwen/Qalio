# AI 客服质检 Copilot

面向电商/本地生活客服主管的演示型 MVP：将脱敏客服对话转换为可复核的风险清单、证据与整改建议。

## 已实现

- CSV 上传与内置 30 条脱敏会话样例
- 规则优先的 5 类风险识别：越权承诺、售后退款、履约发货、情绪升级、服务规范缺失
- P0/P1/P2 风险分级、证据句定位、置信度和建议动作
- 主管工作台：按风险等级、标签和复核状态筛选，查看 Top 整改优先项
- 人工接受/驳回/修改结论；复核结果落入本地 JSONL 反馈集

## 数据格式

CSV 需要包含 `conversation_id`、`date`、`agent`、`customer`、`dialogue` 列。`dialogue` 每行以 `客服：` 或 `用户：` 开头。

## 运行

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

打开 `http://127.0.0.1:8000`。演示数据和反馈数据均为脱敏模拟数据，不能用于真实客户决策。
