# Qalio｜AI 客服质检 Copilot

面向电商与本地生活商家的客服主管，将分散的客服对话转为**可复核的风险队列、原文证据与整改行动**。项目聚焦高风险质检，而非让模型直接替客服回复：高风险结论必须有证据，低置信度与规则冲突会进入人工复核。

> 所有演示与评测数据均为脱敏模拟数据；项目仅用于产品方案与技术验证，不用于真实客户决策。

## 产品问题与取舍

传统抽检覆盖低，主管面对大量会话时难以确定“今天先处理什么”。Qalio 的 MVP 优先解决：在一批会话中定位高风险问题，并给出可追溯证据和下一步动作。

- **做**：风险识别、P0/P1/P2 分级、证据定位、整改建议、主管复核与反馈沉淀。
- **不做**：自动回复用户、自动处罚客服、接入真实生产客服系统。
- **取舍**：宁可将低置信度结论交由人工复核，也不把无证据的模型判断直接用于高风险业务决策。

## 功能

- CSV 导入脱敏会话；内置演示样例。
- 识别 5 类风险：越权承诺、售后退款、履约发货、情绪升级、服务规范缺失。
- 展示风险等级、置信度、对话原文证据与建议整改动作。
- B 端主管工作台：风险队列筛选、风险趋势、Top 整改主题与问题洞察页。
- 人工确认、修改或驳回 AI 结论；反馈写入本地 JSONL，为后续迭代留样。

## 工作流

```text
脱敏 CSV 会话 → 规则拦截 + LLM 语义识别 → 原文证据校验
                                      ↓
                         低置信度 / 规则冲突 → 人工复核
                                      ↓
                            风险队列、根因洞察、整改行动
```

规则承担高精度、可解释的拦截；LLM 补足委婉表达和复杂语义；证据校验与人工复核控制误报风险。

## 评测设计与结果

自建 100 条脱敏模拟会话：80 条开发集，60 条冻结测试集（其中含 40 条委婉表达、否定语境、混合风险与合规反例）。所有方案在同一冻结集评测。

| 方案 | Precision | 高风险召回率 | F1 | 证据准确率 |
| --- | ---: | ---: | ---: | ---: |
| 关键词规则 | 81.0% | 34.7% | 48.6% | 28.3% |
| 单次 LLM（gpt-4o-mini） | 51.1% | 46.9% | 48.9% | 75.0% |
| **Copilot 工作流** | **66.7%** | **77.6%** | **71.7%** | **81.7%** |

Copilot 工作流平均耗时 1.44 秒/会话，17/60 条（28.3%）自动进入人工复核队列。以上结果为自建模拟集结果，不能外推为真实业务效果。

## 技术实现

- **应用层**：FastAPI、原生 HTML/CSS/JavaScript；提供质检总览和问题洞察页。
- **模型层**：OpenAI Chat Completions，温度 0，JSON Schema 风格约束输出标签、优先级、证据和建议。
- **评测层**：冻结集、原始预测 JSONL、统一 Precision / Recall / F1 / 证据准确率打分脚本。
- **安全边界**：`.env`、评测原始输出和人工复核反馈均被 Git 忽略。

## 快速开始

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

打开 `http://127.0.0.1:8000`；问题洞察页为 `http://127.0.0.1:8000/insights`。

### 运行评测

```bash
python evaluation/build_dataset.py
python evaluation/score.py
```

如需运行 LLM 基线与 Copilot 对照，在根目录创建 `.env`：

```env
OPENAI_API_KEY=你的密钥
QA_EVAL_MODEL=gpt-4o-mini
```

```bash
python evaluation/llm_baseline.py
python evaluation/copilot_workflow.py
python evaluation/score_predictions.py evaluation/results/copilot_workflow.jsonl
```
